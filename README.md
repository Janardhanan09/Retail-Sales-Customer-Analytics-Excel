# Retail Sales & Customer Analytics using Excel

## &#128202; Project Overview

This project focuses on analyzing retail sales and customer data using Microsoft Excel.

The project includes data analysis, sales performance tracking, customer analysis, and an interactive Excel dashboard to identify important business insights and trends.

## &#127919; Project Objectives

- Analyze overall retail sales performance
- Identify top-performing products and categories
- Analyze customer purchasing behavior
- Track sales and order trends
- Identify key business insights from the dataset
- Create an interactive Excel dashboard for data visualization

## &#128269; Key Analysis

- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value
- Sales by Category
- Sales by Product
- Sales by Region
- Monthly Sales Trends
- Top-Performing Products
- Customer Purchase Analysis
